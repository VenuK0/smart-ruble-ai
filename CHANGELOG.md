# История разработки SmartRubleAI

## v0.3.0-dev (дизайн в разработке; релиз не выпущен)

- Раздел «Проверка аномалий» получил аналитическую панель с воспроизводимым набором, топ-10 относительных оценок и подробными признаками выбранного продавца.
- API синтетического антифрода возвращает шесть измеренных признаков для топ-10; модель и генератор данных не менялись.
- Явно разграничены оценка Isolation Forest, простые пороговые наблюдения и тестовые сценарии; никакие выводы о реальном мошенничестве не делаются.
- Добавлены адаптивные стили, расчётные JS-функции, тесты API и интерфейса, CI-контроль новых файлов.


- Переработана история операций: поиск по чеку, продавцу и товару, фильтрация по решению, сводка по видимым операциям, просмотр каждой позиции и объяснений модели.
- Добавлен индикатор целостности цепочки журнала с честным указанием ограничений прототипа: журнал в памяти, до 100 последних операций, нет настоящей очереди согласования.
- Уточнены формулировки на экране проверки чеков: нераспознанная категория, статус необходимости ручного решения и более читаемые причины.
- Добавлены модуль фильтрации/итогов истории и Node-тесты его расчётов, тесты ресурсов и интерфейса, сохранён CSV-экспорт.


- Полностью переработан экран проверки чеков: таблица позиций с пересчётом каждой строки и итоговой суммы, контекст активной сметы, понятный результат по категориям и причинам решений.
- Добавлен отдельный модуль клиентской проверки цен/количеств, согласованный с ограничениями API, и тесты на копейки, дробные количества и лимит 100 позиций.
- После успешной проверки форма блокируется до явного действия «Новый чек»; повторная отправка того же документа по ошибке не создаёт новый расход.
- Проверка остаётся демонстрационной, все решения и списания по смете выполняются серверной симуляцией; финансовое ядро не изменялось.


- Переработано боковое меню: группа «Работа со средствами» (обзор, сметы, чеки, история) и группа «Аналитика» (аномалии, экономическая оценка).
- На компьютере меню сворачивается до панели иконок шириной 78 px; состояние сохраняется в браузере, ссылки на GitHub и API остаются доступными.
- На телефоне меню всегда показывает названия разделов независимо от настройки компьютера; переключение и восстановление проверяются отдельными тестами.


- После создания сметы её статьи и лимиты выводятся сразу под реестром, перед формой создания следующей.
- Поле новой сметы предлагает следующий свободный номер (`грант-2026-2` после `грант-2026` в примере) и больше не подталкивает к созданию дубликата.
- На карточке активной сметы добавлен быстрый переход к проверке чека.


- По итогам визуальной проверки переработана страница смет: компактный редактор в две колонки на ПК, ясное пустое состояние и аккуратная мобильная раскладка.
- Убрана лишняя фокусируемость всей области страницы, которая могла вызывать чёрную рамку вокруг интерфейса.


- Рабочий стол стал ориентирован на последовательный сценарий: создание сметы → проверка чека → анализ журнала. Добавлено начальное состояние с понятными действиями.
- Реестр смет получил поиск, выбор активной сметы, расчёт освоения лимитов по категориям и выгрузку в Excel-совместимый CSV.
- На форме чека появился расчёт предварительной суммы; в истории — экспорт отфильтрованных записей с безопасной обработкой CSV-формул.
- Дополнительные адаптивные стили для реестров, таблиц, форм, индикаторов и небольших экранов. API и расчётная логика сохранены.


- Оставлена единая светлая тема Graphite Red: переключатель и ресурсы тёмной темы удалены.
- Знак ₽ поднят на 7 единиц в SVG для вертикального оптического центрирования; компактная надпись слегка облегчена без замены векторного шрифта.

- Исправлена нестыковка между большим референсом и маленьким логотипом в боковой панели: вместо наборного текста подключены те же векторные очертания букв из `logo.svg`.
- Тонкие углы красного контура, оптически центрированный ₽, знак 56 px, больше места для названия и подписи, фирменная светлая подложка в светлой теме.

- Выбрано русское название интерфейса «СмартРубль AI» и подпись «Контроль грантов и расходов».
- Геометрия контуров, знак ₽, пропорции и расстояния полностью перерисованы под утверждённый референс. Горизонтальный SVG содержит тёплый фон для видимости в тёмной теме GitHub и векторизованную типографику.
- Утверждён финальный знак «Контур рубля»: все четыре угла красные (`#BB080B`), символ ₽ чёрный (`#191919`). Обновлены три SVG, favicon и браузерный кэш-ключ.
- Фирменный знак «Контур рубля» подготовлен в редактируемом SVG; создан отдельный favicon.
- Палитра Graphite Red: Milano Red, Carbon Black, Carrara, Chalk, Slate.
- Брендинг подключён к боковой панели, заголовкам страниц, вкладке браузера и README.
- Сохранены логика финансовых операций, маршруты и техническое имя SmartRubleAI.
- Обновлены боковая навигация, таблицы, формы и кнопки в единой дизайн-системе.
- Ранее исследовались две темы; от тёмной отказались в пользу одного фирменного оформления.
- Улучшено мобильное меню: затемняющая подложка, закрытие вне панели, Esc и при расширении окна.
- Финансовая логика не изменена.



## v0.2.0-rc.2 (предварительная версия интерфейса)

- Светлый интерфейс для финансовых контролёров вместо неоновой Research Console.
- Отдельные URL для обзора, смет, проверки чеков, истории, антифрода и экономических сценариев.
- Выбор активной сметы между страницами; таблицы, фильтры истории и формы.
- Подписи на русском, предупреждения сведены к минимуму.
- Тесты маршрутов и ресурсов; проверка JavaScript в CI.
- Сохранены текущие API и исследовательские алгоритмы.



## v0.2.0-rc.1 (7 ноября 2026, предварительная версия для проверки интерфейса)

- Безопасная проверка сумм и лимитов, в том числе десятичных значений.
- Идемпотентность операций по ID чека, синхронизация в одном процессе и откат незавершенных операций.
- Строгая проверка входных данных API.
- Интерактивная консоль /demo: смета, чек, журнал, синтетический антифрод и условные экономические сценарии.
- Повторяемые стресс-эксперименты для классификации и антифрода на разных случайных наборах.
- Юнит- и API-тесты, GitHub Actions, документация по сценарию защиты и ограничениям.
- Важно: всё еще учебный симулятор, без реальных платежей и промышленной безопасности.

## v0.1.0 (опубликован 7 ноября 2026)

Исходная коллективная конкурсная версия:
- Разбор сметы по правилам.
- TF-IDF + логистическая регрессия для позиций товаров.
- Имитация логики целевых лимитов и разделение APPROVE / REVIEW / REJECT.
- Графовый антифрод (NetworkX + Isolation Forest).
- Цепочка SHA-256, FastAPI, тесты и экспериментальные метрики.

Авторы проекта: Окунев В. И. и Штунь А. Р. Коммит v0.1.0: 6ad8428.
