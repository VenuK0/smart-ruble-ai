# Как участвовать в разработке SmartRubleAI

SmartRubleAI — открытый исследовательский прототип, созданный Окуневым В. И. и Штунь А. Р. при научном руководстве Рзун И. Г. Новые предложения и исправления приветствуются, если они не выдают симулятор за действующую платёжную систему.

## Подход к работе

- **main** — основная ветка проекта с проверенными изменениями.
- **v0.x.y** — версии в Releases; исходная конкурсная версия доступна как v0.1.0.
- **coursework-analytics** — отдельная линия индивидуальной курсовой, если она будет создана; общие авторские материалы остаются атрибутированными.
- Для объёмной функции используйте краткоживущую рабочую ветку и pull request. Долгоживущую «форумную» ветку поддерживать не планируется.

## Подготовка среды

1. Установите Python 3.11+ и создайте .venv.
2. Установите зависимости: python -m pip install -r requirements-dev.txt.
3. Выполните тесты: python -m unittest discover -s tests -v.
4. Запустите API: python -m uvicorn smartruble.api:app --app-dir src --host 127.0.0.1 --port 8000.

Рекомендуемый порядок pull request: описание проблемы → исправление → тесты → документация → скриншот (при изменении интерфейса) → проверка GitHub Actions.

## Какие изменения особенно полезны

- Валидация и граничные случаи денежных операций.
- Улучшение классификации на независимых наборах данных без роста ошибочных автоматических одобрений.
- Воспроизводимость экспериментов и честное описание ограничений.
- Интерфейс с доступной навигацией и удобной работой на мобильных экранах.

## Безопасность

В прототипе нет авторизации, постоянной БД и промышленного платёжного контура. Не публикуйте сервер в открытый интернет и не загружайте настоящие финансовые документы или персональные данные. Подробнее: docs/SECURITY_LIMITATIONS.md.

## Авторство и лицензия

Код распространяется по MIT, с сохранением уведомления об авторах. Не удаляйте атрибуцию исходных соавторов; у экспериментальных метрик и расчётов должно быть ясно указано происхождение.
