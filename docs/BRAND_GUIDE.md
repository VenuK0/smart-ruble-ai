# Фирменный стиль «СмартРубль AI»

**Основное написание:** СмартРубль AI  
**Подпись:** Контроль грантов и расходов  
**Техническое имя проекта / GitHub:** SmartRubleAI (не менять в URL, импортах и научной истории).

## Концепция логотипа

Утверждённый пользователем вариант №1 — **«Контур рубля»**. Утверждённая окончательная версия: **все четыре угла контура — Milano Red `#BB080B`, символ ₽ — Carbon Black `#191919`**. Углы остаются разомкнутыми, как в первом выбранном варианте. Контур символизирует контроль конкретной операции; знак рубля — расчёты в национальной валюте. Символ разработан в SVG-кривых и не зависит от набора иконок, шрифтовых файлов или внешних сервисов.

Файлы находятся в [папке brand](../src/smartruble/web/brand):

| Файл | Использование |
|---|---|
| `logo.svg` | Полный горизонтальный логотип с подписью, README и фирменные материалы |
| `mark.svg` | Компактный знак для боковой панели и небольших интерфейсных элементов |
| `favicon.svg` | Контрастная иконка с красным контуром и чёрным ₽ на фоне Carrara `#F0EDE8`, вкладка браузера / иконка приложения |

## Палитра Graphite Red

| Роль | Название | HEX |
|---|---|---|
| Основной текст / строгие кнопки | Carbon Black | `#191919` |
| Фирменный акцент / все углы контура / AI | Milano Red | `#BB080B` |
| Основной тёплый фон | Carrara | `#F0EDE8` |
| Дополнительные поверхности | Chalk | `#E8E5DF` |
| Вторичные нейтральные элементы | Slate | `#C9C5BE` |

В интерфейсе допускаются служебные оттенки этой системы для границ и выделений. **Зелёный** сохраняется исключительно для успешных операций, **жёлтый** — для ручной проверки, **красный статус ошибки** не должен быть единственным сигналом: статус сопровождается текстом.

## Правила

1. Во внешних материалах — «СмартРубль AI», в репозитории и API сохраняется техническое название `SmartRubleAI`.
2. Подпись использовать дословно: **«Контроль грантов и расходов»**.
3. Не перекрашивать фирменный контур в графитовый и не заменять чёрный знак ₽ белым. Знак можно ставить отдельно только тогда, когда продукт уже назван в контексте (favicon, меню, аватар).
4. Не растягивать и не деформировать; оставлять вокруг знака свободное поле не меньше четверти его ширины.
5. На светлом фоне: **красный контур и чёрный ₽**. На тёмной поверхности используйте знак внутри светлой подложки Carrara; не меняйте цвет ₽ на белый и не делайте углы разноцветными.
6. Без свечений, стеклянности, градиентов, имитации нейросети и декоративных банковских щитов.
7. Типографика интерфейса: системный стек `Segoe UI`, `Arial`, sans-serif. Кириллица обязательна.
8. Упоминание демонстрационного характера продукта сохраняется в интерфейсе и документации, но **не входит** в логотип.
9. SVG — редактируемый первоисточник; при экспорте в растровый формат сохранять пропорции и цветовые коды.
